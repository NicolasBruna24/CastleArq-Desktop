### 2.3 Reutilizacion vistas (sin duplicacion)
- Cada vista se crea UNA sola vez en __init__
- Mover vistas de QScrollArea a QStackedWidget
- Eliminar QScrollArea como central despues de migrar

### 2.4 Relacion Sidebar <-> QStackedWidget
- sidebar.page_changed.connect(_on_sidebar_page_changed)
- Handler solo cambia setCurrentIndex(index)
- Navegar NO debe iniciar/detener/reiniciar Core

### 2.5 Conexiones senales y slots
- Mismo patron actual, views en QStackedWidget
- ModelExplorer -> _on_model_selected, etc.
- LocalLibraryView -> _on_artifact_selected, etc.
- ChatView -> _on_chat_session_closed

### 2.6 Inicializacion y imports opcionales
- Mantener try/except ImportError para vistas opcionales
- Si falla import, QLabel informativo en pagina correspondiente
- Cualquier exception durante init de vista debe capturarse, nunca propagarse

### 2.7 Conservacion estado al cambiar pagina
- _selected_model se conserva en MainWindow; ModelExplorer pagina 1 mantiene estado interno
- _selected_artifact se conserva; LocalLibraryView pagina 2 mantiene estado
- _chat_view.has_session funciona independientemente de pagina activa
- _pending_library_refresh independiente de pagina actual

### 2.8 Evitar que navegacion inicie/detiene/reinicia Core
- Regla estricta: _on_sidebar_page_changed solo setCurrentIndex
- No llamar a _controller.request_startup(), _on_start(), lifecycle
- senal page_changed solo emite indice

## 5. Diagnostico 18 Fallos

Hechos comprobados:
- 38 tests directos LocalLibraryView pasan completamente
- 18 fallos son AttributeError: 'MainWindow' object has no attribute '_local_library' etc.
- La logica de biblioteca funciona; fallos son setup de test

Causa raiz:
- MainWindow.__init__ tiene bloques try/except ImportError conditionales
- Tests crean MainWindow() sin contexto adecuado para inicializar todos los atributos
- Los 38 tests que pasan prueban LocalLibraryView directamente, sin pasar por MainWindow

Conclusión: Los 18 fallos son errores de configuracion de tests, no regresiones de codigo.
